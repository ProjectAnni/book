## 定义

`Anni` 元数据源（`Anni Metadata Source`，以下简称元数据源）是指实现了 `Anni` 元数据协议中定义接口的服务端应用程序。其核心功能有三：

1. 对专辑元数据的查询
2. 对标签及相关图的查询
3. 给定关键词的专辑元数据搜索

## 底层协议

Anni 元数据协议基于 `GraphQL` 协议。客户端通过 `GraphQL` 查询语言向元数据源发起请求，元数据源返回符合 `GraphQL` 规范的响应。

## 结构定义

```graphql
type AlbumInfo {
  albumId: String!
  title: String!
  edition: String
  catalog: String!
  artist: String!
  artists: JSONObject
  date: String!
  tags: [TagInfo!]!
  discs: [DiscInfo!]!
}

type DiscInfo {
  title: String
  catalog: String!
  artist: String
  artists: JSONObject
  tags: [TagInfo!]!
  tracks: [TrackInfo!]!
}

type TrackInfo {
  title: String!
  artist: String!
  type: String!
  artists: JSONObject
  tags: [TagInfo!]!
}

type TagInfo {
  name: String!
  type: String!
  includes: [TagInfo!]!
  names: JSONObject!
  includedBy: [TagInfo!]!
}
```

## 专辑元数据查询

```graphql
type MetadataQuery {
  album(albumId: String!): AlbumInfo
  albumsByTag(tag: String!): [AlbumInfo!]!
}
```
